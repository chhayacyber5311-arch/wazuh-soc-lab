# wazuh-soc-lab
SOC Home Lab using Wazuh SIEM for threat detection and log analysis

Wazuh SOC Home Lab (AWS Based)

Overview-
This project demonstrates a SOC (Security Operations Center) home lab setup using Wazuh SIEM on AWS cloud infrastructure. The lab simulates real-world attack scenarios and detects them using log analysis.

Lab Setup-
1. Wazuh Server deployed on AWS EC2
2. Wazuh Agent installed on target machine
3. Communication configured between server and agent

Attack Simulation-
1. Performed network scan using Nmap
2. Targeted open ports on agent machine

Detection & Monitoring-
1. Wazuh successfully detected suspicious activity
2. Alerts generated for port scanning attempts
3. Logs analyzed using Wazuh dashboard (OpenSearch)

Tools Used-
> Wazuh SIEM
> Nmap
> AWS EC2
> Linux (Ubuntu)
